# Student Group Management System

## Overview
The Student Group Management System is designed to efficiently organize students into balanced study groups based on academic performance and language preferences. It supports dynamic group formation and flexible management to enhance collaborative learning.

## Features
- Student addition, removal, search, and display using unique IDs  
- Dynamic group creation based on performance levels (low, mid, high)  
- Waiting list management for unassigned students  
- Language and subject management with fast lookup using hash maps  

## Data Structures Used
- **Linked Lists** for managing students, groups, and waiting lists  
- **Queues** (implemented using linked lists) for waiting list operations  
- **Hash Maps** for efficient language and subject management  

## Core Components
- **Node Classes**: Handle individual students, groups, and waiting list entries  
- **Linked List Classes**: Manage members, groups, and waiting lists  
- **Hash Map Classes**: Store and manage languages and subjects  

## Usage
This module can be used to:
- Add and manage students  
- Create and manage study groups  
- Assign and reshuffle students dynamically  
- Register and manage subjects and languages  

## Purpose
The system aims to support collaborative learning by ensuring balanced group composition while maintaining flexibility and efficiency in group management.
